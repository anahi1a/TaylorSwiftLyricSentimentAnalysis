# Song Lyric Sentiment Analysis
### Anahita Gupta

This project analyzes sentiment patterns in Taylor Swift’s song lyrics using Natural Language Processing (NLP) techniques. The goal is to examine emotional trends across albums and identify recurring thematic elements such as day and night references.

---

## Overview

The project includes:

- Text preprocessing (lowercasing, punctuation removal, stopword removal)
- Tokenization of lyrics
- Word frequency analysis
- Thematic feature extraction (day/night/time references)
- Sentiment analysis using NLTK’s VADER sentiment analyzer
- Visualization of sentiment trends across album years

---

## Steps

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run the notebook:

```bash
ts.ipynb
```

The notebook performs preprocessing, sentiment analysis, and visualizations of lyrical trends.
